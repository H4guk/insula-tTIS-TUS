## 1. Run 拒否は解決 → 残る壁は「ボクセルシーンが空」に確定

**Run 拒否（`Unable to run simulation. Please check your simulation settings.`）は解決した。**
原因は **同一ソリッドに材料σと Dirichlet BC を両方付けていたこと**で、BC を
**電極の外側の面**（`xc.GetFaces` → `IsPlanarFace` → 頭の中心から最も遠い平面）に移すと Run が完走し、
初めて `Input.log` が生成された。

しかし結果は依然 **全点 NaN**。`Voxeler.log` の
**`Voxel Scene Memory Consumption: 0.001196 kB`＝ボクセルシーンがほぼ空**が本丸だった。
σを付けた59組織すら1つも焼かれておらず、ソルバーは
`Degree of freedoms: 12449814 total, 0 unknowns, 0 Dirichlet points` で何も解かない。

### 否定した仮説

| 疑ったもの | 結果 |
|---|---|
| 同名衝突（HDF5 `attribute already exists`） | ✗ クリーンセッションでも再現。HDF5 は**症状**であり原因ではない |
| ViP（Yoon-sun）固有の問題 | ✗ **自作の単純なソリッド（`CreateSolidBlock` の箱）でも再現** |
| セッション状態の汚れ | ✗ **リロード直後の素のセッションでも再現** |
| 結果ディレクトリに残った過去ファイル | ✗ 中身は当該実行の `Input.h5` と `Voxeler.log` の2つだけ |
| ViP がメッシュ（非ソリッド）だから焼けない | ✗ 本物のソリッド Body も焼けていないので型は分かれ目でない |

### 最小再現ケース（ViP・電極・BC を使わずに再現する）

```python
box = xc.CreateSolidBlock(model.Vec3(80.,240.,1550.), model.Vec3(120.,280.,1590.))
sim = emlf.ElectroQsOhmicSimulation(); doc.AllSimulations.Add(sim)
ms = sim.AddMaterialSettings(box); ms.ElectricProps.Conductivity = 0.5
sim.UpdateAllMaterials()
ggs = sim.GlobalGridSettings; p = ggs.DiscretizationModeProp
p.set(p.findValue('Manual')); ggs.MaxStep = [2.,2.,2.]
sim.UpdateGrid(); sim.CreateVoxels()
# → Voxeler.log: Error: The material component 'BOXTEST_body' is not being considered
#    Start voxeling / Voxeling succeeded.（空のまま成功）
```

**本命の仮説**: `AddMaterialSettings` は `sim.AllComponents` に載るが、
**エンティティが sim の Model / solid region に登録されていない**（v10 で `AssignEntities` が
廃止された分の代替手順が抜けている疑い）。ソルバー警告 `Check your model and solid region settings.` と整合。

**次の一手**: ①**GUI で同じ最小 sim を作って Create Voxels**（lec6〜8 は GUI で成功していた）→
焼ければ GUI と Python の sim 構造を突き合わせて不足設定を特定 → Python に翻訳
②焼けなければ ZMT サポート/フォーラムへ最小再現ケースで照会。

## 2. 工程1〜4 を1つずつ検証（すべて「原因ではない」と確定）

| 工程 | 検証内容 | 結果 |
|---|---|---|
| 1 モデルの用意 | 閉じた立体か（`IsClosedSolidBody`・`MeasureVolume`） | 型は `TriangleMesh`／`IsClosedSolidBody=False` だが、**ソリッドの箱も焼けない**ので原因ではない |
| 2 座標系検出 | グリッド範囲 X4–202 / Y162–352 / Z1450–1665 が頭を囲むか | 灰白質・頭蓋・電極すべて範囲内（電極とグリッド上限の余裕 11mm） |
| 3 島皮質 ROI | ノート基準「MNI±38 相当・頭皮 3–4cm 深」 | 左右オフセット **34.5mm 一致**・白質内部（−5.6mm）・**頭皮 25.0mm は基準外**（→ #9） |
| 4 電極配置 | 皮膚に接触しているか（すき間＝空気で電流が入らない） | 4枚すべて皮膚層から **±0.25mm**＝またいでいる。サイズも直径20mm・厚3.5mmの円板が20〜25°傾いた形で設計どおり |

### 判明したこと（再利用価値のある知見）

- **ViP はライセンス保護されている**: `xc.ConvertToSolid(skin)` は
  `[ERROR] [XCore.CLog] Cannot convert licensed part` で失敗する。＝ViP を Body 化する回避ルートは使えない。
- **符号付き距離は正常に機能している**: ROI 中心から `Cerebrum_white_matter` は **−5.6mm（内部）**、
  `Skin` は **+25.0mm（正）**。Skin は**薄い層**なので頭の内部の点は「層の外側」になるだけ。
  ＝2026-07-21 の「Skin は符号付き距離を返さない」は「薄い層に内外判定は使えない」が正確な表現。
- **材料設定の正しい列挙口は `sim.AllSettings`**（`MaterialSettings` 型が `ElectricProps` を持つ）。
  `sim.AllComponents` はエンティティ参照側なので σ を持たない。
- 起動時の `Failed to define static enum ...`（`RecruitmentEvaluator`・`_emfdtd_impl`）は
  ニューロン解析・FDTD 用の初期化ノイズで、Electro QS には無関係＝**無害**。

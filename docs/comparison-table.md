## 3. 結論

> **① 焦点性の差は「大きさ」ではなく「焦点を結ぶか否か」。**
> TUS は標的の近くに焦点を1つ結ぶ（脳内最大が標的の 2.83倍で標的から 10.2mm・標的レベル以上は ROI の 1.7倍）。
> tTIS は焦点を結ばない（島皮質のまわりはほぼ平らで、近くの山の頂でも標的の 1.28倍。標的レベル以上は標的を含む一塊として ROI の 8.6倍に広がる。脳内最大は延髄の表面で標的の 4.59倍）。
> 島皮質は焦点ではなく**電極へ向かう裾の途中**にある。
>
> **② 標準安全域での深部到達は tTIS の方が目安に近い。どこまで届くと言えるかは目安の置き方で変わる。**
> 文献の有効範囲の下端を両手法の目安にし、振幅にそろえると、**ROI 平均で目安の 113%（tTIS）対 42%（TUS）**。
> 範囲の中点を目安にすると 65% 対 18% で、どちらも届かない。**tTIS の方が近いという向きはどちらでも同じ**だが、倍率（2.7〜3.6倍）は目安の置き方で動く。
> 下端を超える ROI 体積は **74.5%（tTIS）対 0.0%（TUS・実質 1〜2 セル）**。TUS は ROI の最強セルだけ見れば下端を超える（102%）が、**それは ROI のごく一部でしか成り立たない**。
> 中点を超える ROI 体積はどちらも 0.0%（`results/ti_roi_threshold_fraction_2026-10-20.txt`）。
>
> **③ 焦点性と深部到達で優劣が逆転する——これが本比較の核心。**
> **tTIS は焦点を結ばないが、標的での強度は有効範囲の下端を超える**（ROI 平均で 113%・ROI の 74.5% が下端超え。中点では 65%＝壁は 2mA という電流上限＝絶対強度）。
> **TUS は焦点を結ぶが、安全上限では標的に下端の 42% しか届かない**（振幅で比べた値。壁は焦点でなく皮下脂肪の高圧＝頭皮 near-field が MI<1.9 を縛る）。
> ＝**「よく絞れるが弱い TUS」と「絞れないが強い tTIS」**。どちらの弱点を潰せるかが次の設計判断になる。

**条件つきの推奨**: 島皮質ターゲットでは「**空間的な絞り込みなら TUS・標的での強度と簡便さなら tTIS**」。
ただし ①〜③ より、**現行の標準実装ではどちらも臨床有効域に届いていない**のが実態で、
**改善の方向は手法ごとに違う**——tTIS は**焦点を作ること**（多対最適化）、TUS は**頭皮を守りながら出力を上げること**
（大開口・分散照射・アレイによる収差補正）。

**正直に併記すべき2点**:
1. **TUS の優位は「標的レベル」で 4.9倍、「半分レベル」では 3.0倍に縮む**（TUS もビーム経路で脳の 6.06% に及ぶ）。
2. **ROI 内の到達率は両者ほぼ同じ**（47.3% / 44.1%）＝**どちらも島皮質の半分弱しか標的レベルに届いていない**。

## 4. 限界

### 4-1. 両手法に共通（比較の土台そのものの限界）

- **1体のモデル**: Yoon-sun（小柄な26歳女性）1体固定。集団平均ではない。群レベルで安定な結果には**島皮質で約20モデル必要**（Inoue 2025）。頭蓋厚・脳サイズの個人差は反映しない。
- **粗い球 ROI**: Yoon-sun は島皮質を独立組織として持たないため**半径10mm の球**で切っている（先行研究は FreeSurfer の皮質表面頂点）。ROI はモデル上「白質」ラベルの領域に載る。**両手法で同一の球なので比較の公平性は保たれる**が、皮質形状に沿った ROI ではない。
- **ROI は実体オブジェクトではない**: 統合プロジェクトでも ROI は**座標 (99.1, 295.0, 1562.2)・r=10mm の共有**であって、球のソリッドが1つある形にはなっていない（両手法のスクリプトが同じ定数を参照する）。
- **解像度の天井**: Sim4Life.lite の 2,000万セル上限（**シミュレーション単位**）により、フルヘッドでは**頭部 1mm が実質下限**。これが TUS の周波数上限（250kHz 帯）も決めている。
- **`Commissura_anterior` がボクセル化されない**（頭部 1mm でも 0 voxel）。極細の交連線維で ROI から遠く体積も無視できるため結果に影響しない。
- **脳は組織名で決めている**: 両手法とも Yoon-sun の組織名で脳実質 12 組織（1041.5 mL）を選んだ。Yoon-sun のセグメンテーションの精度にそのまま依存する。脳脊髄液・硬膜・脊髄・神経・下垂体は脳に含めていない。
  （2026-10-14 GH #17: 以前は tTIS を σ 帯・TUS を (c, ρ) 帯で決めていて「物理量が違う以上そろえられない」としていたが、組織名でそろえられた。帯には腱・靭帯・気管・神経〔tTIS〕、唾液腺・食道・下垂体〔TUS〕が混ざっていた）

### 4-2. tTIS 固有

- **電極モデルの簡略化**: 我々＝σ 1.6 の円板1層（直径 20mm・厚 3.5mm）／Inoue 2025 ＝導電ゴム（σ 0.1・厚 1mm）＋生理食塩水スポンジ（σ 1.6・厚 5mm）の 20mm 角。
- **（訂正）旧い σ 帯の混入**: 以前の脳マスク（σ 0.33〜0.44）には Nerve 13.1・Trachea_wall 9.3・Tendon_ligament 6.9・Eye_lens 0.4 mL（計 29.7 mL）が混ざり、「電場が弱いので影響なし」としていたが、**旧い「脳内最大 10.7倍・96.6mm」はその腱・靭帯の値だった**。現在は組織名で脳を決めている（§1・§4-1）。
- **絶対電流の独立検算が取れていない**: 規約は σ 照合で確定しているが二重確認ではない（`J` の面積分が約25%過小・[#13](https://github.com/H4guk/insula-tTIS-TUS/issues/13)）。
- **σ セットの選択が結果に効く**: IT'IS **LF** 5.0 を採用したことで、非 LF の 2 kHz 評価値に対し**脳組織は 4〜5倍高く、頭蓋骨と Dura は逆に低い**。
- **先行研究と頭部モデル・ソルバー・電極モデルが異なる**ため、選択性 ≈0.40 との**完全一致は求めず桁と傾向で照合**している。

### 4-3. TUS 固有

- **周波数天井**: セル上限により **250kHz が上限帯**（350kHz 以上・特に文献で多い 500kHz は不可）。250kHz / 1mm は **6セル/λ ＝数値分散のフロア**。より高周波の焦点（<1cm）や高精度には Science 版 / HPC が要る。
- **連続正弦波近似**: 定常調和解 `p(x,y,z,f)` を評価している。実 TUS は**パルス駆動（低 duty）**なので ISPTA（時間平均・熱）は本結果よりずっと低い。**MI・ピーク圧・ISPPA・選択性はパルスでも不変**（振幅・比の量）だが、**熱（TIC・温度上昇）は本モデルで評価していない**。
- **CT 無し・一様骨近似**: 頭蓋を DB の一様値で近似。実頭蓋は多孔質で個人差が大きく、**音速・減衰・位相収差の最大の不確かさ源**。個別 CT による収差補正は対象外。
- **単一素子**: フェーズドアレイ（電子ステアリング・収差補正）は tier-1 外。**頭蓋収差は補正なしで残る**。
- **参照振幅の線形スケール**: 1MPa 音源で回して線形にスケールしている（選択性は駆動非依存）。
- **安全駆動は ROI の最強セルでしか有効域に触れない**: MI<1.9 で音源 0.156 MPa まで上げられるが、
  **ISPPA が下端 3 W/cm² を超えるのは ROI 4186 セル中 1〜2 セル（0.05% 未満）**。ROI 平均では 0.531 = 下端の 17.7%（振幅に直すと 42%・§2）。
  「有効域に入る」という言い方は**最強の1セルについてのみ**成り立つ。

### 4-4. この比較の設計上の限界

- **標準実装同士の比較**: tTIS の**位置最適化は未実施**（#8）。最適化すれば絶対強度は変わりうるので、本結果は「Montage I ＋ 2mA」という**特定の標準構成についての結論**。
- **「効き始めるライン」は文献の範囲から両手法で同じ取り方をしたが、意味は完全には同じでない**（GH #19）:
  tTIS の 0.2〜0.5 V/m は tACS で神経調節が報告された電場の範囲（Inoue 2025 はこの範囲から 0.3 V/m を採用。本書の「中点」は算術の中点 0.35 V/m。発火の閾値ではない）、TUS の 3〜30 W/cm² はヒトの研究で通常設定される ISPPA の範囲（Sharif 2025）。どちらも閾値ではなく「効果が報告されている強さの範囲」なので、**両方とも下端を目安にし**、ISPPA は振幅に直して（√）比べた。中点を目安にした値を幅として併記する（§2・結論②）。
  以前は tTIS を 0.3 V/m（Inoue の採用値）・TUS を下端で割り、しかも TUS は強度（振幅の2乗）のまま割っていたため、「tTIS の方が 4倍近く届く」と書いていた。これは目安の取り方と量の次数の違いが重なった値で、言えない。
- **ほかの非対称**（GH #19・直せないものを含む）:
  - **周波数**: TUS は Sim4Life.lite のセル上限で 250 kHz に縛られる（§5-3）。文献で多い 500 kHz なら焦点は細くなる＝**TUS に不利な道具の制約**。
  - **最適化の度合い**: tTIS の電流比は Inoue 2025 の島皮質向けの最適値。TUS は単一素子で、頭蓋収差の補正もない＝**tTIS の方が標的に合わせて調整済み**。
  - **安全上限の性質**: tTIS の合計 2 mA は tES の慣行、TUS の MI<1.9 は FDA の診断用超音波の上限。どちらも「その分野の標準」だが、同じ危険度をそろえた値ではない。

## 指標の定義（ここが計測の芯）

| 指標 | 定義 | 備考 |
|---|---|---|
| TI 包絡線 | `2·min(|E1|, |E2|)`（Grossman の等方近似） | ペア1・ペア2 を**同一グリッド**で Run した E 場から作る |
| `TI_ROI` | ROI 内の**セル体積重み平均** | グリッドが非一様（graded）なので単純平均は歪む |
| **選択性** | **非標的領域の平均 EFE / 標的（ROI）の平均 EFE**（小さいほど良い） | Inoue 2025 の **Montage I ≈ 0.40** と照合する |
| 活性化閾値 | **0.3 V/m**（有効範囲 0.2–0.5 V/m の中点・Inoue 2025 採用値） | 「効いている」の判定に使う |

**選択性の定義を先行研究に合わせた理由**: 当初案は `ROI平均 / top1%平均` だったが、
先行研究と同じ定義にすれば **≈0.40 という外部の答え合わせが無料で手に入る**。独自定義に利点がない。

**電流**: Inoue 2025 の群レベル最適値 **I₁ = 0.891 mA / I₂ = 1.109 mA**（制約 I₁+I₂ = 2 mA）。
1V 駆動で計算し、**電場は線形なので後段でスケール**する。

### 電流スケールの求め方（2026-08-12 確定・`current_scale.py` / `ti_analysis.py`）

1V 駆動時の電流 `I_1V` を **`El. Loss Density` の体積積分 P** から求める: **`I = 2P/V`**。
係数 2（＝ `P = ½VI` の振幅規約）は**推定ではなく照合で確定**した——σ を場から逆算し、
**`σ = 2·loss/|E|²` が既知の σ を有効セルの 61.1% で再現**（`σ = loss/|E|²` は 12.1%）。
既知の σ は監査で全部分かっているので（→ `material-audit.md`）、どちらの式が当たるかを
数えるだけで規約が決まる。

★**スケールを省略できない**: TI は `2·min(s₁|E1|, s₂|E2|)` で **min が非線形**なので、
s₁/s₂ が変われば分布の形が変わる。一様なスケールなら選択性は不変だが、
**2ペアで別の係数を掛けるので不変にならない**（「選択性は比だから電流スケールは要らない」は誤り）。

⚠️ `J` の面積分による独立検算は**約25%過小で面の位置にも依存する**（→ [#13](https://github.com/H4guk/insula-tTIS-TUS/issues/13)）。
規約は σ 照合という別経路で確定しているので結論には影響しないが、絶対値の二重確認は取れていない。

## 解決すべき課題（Issue 化済み）→ **3件すべて決着（2026-08-12）**

### ✅ #9 島皮質 ROI の頭皮からの深さ — **測り方の誤りだった**
- **基準は 40mm に一本化**した。実測 **40.0mm ＝ 基準ちょうど**で、**ROI は動かさない**。
- 「25.0mm」は `GetEntityPointDistance` の**最近傍面**までの距離で、その最近傍点は
  **(92.0, 299.1, 1538.6) ＝ ROI の真下 23.6mm・外側頭皮より 36mm 内側**の耳の高さの点
  ＝**外耳道系の皮膚面**であって頭皮ではなかった。
- 正しい測り方＝ROI の +Y 側（頭の外）に探査点を置き `ClosestPosition` で頭皮へ落とす
  （`Skin` は薄い殻で符号付き距離を返さないためレイキャストは使えない）。実装は `define_insula_roi.py` ③。
- **ROI を動かす案は採らない**: 15mm 内側へ寄せると正中から 19.5mm ＝ MNI |x|≈21mm で
  **大脳基底核の領域になり、標的が島皮質でなくなる**。
- ⚠️ レポート表記: Yoon-sun は MNI の 0.90 倍なので **40.0mm は MNI 換算 44mm 相当**。
  「浅すぎる」ではなく「**Yoon-sun では島皮質が相対的に深い**」が正しい。

### ✅ #10 材料σの記録と実測の食い違い — **両方本物・出所が違っただけ**
- ノートの「**0.0002**」は**非 LF DB の分散モデルを 2 kHz で評価した Skin（乾燥皮膚）**の値。
  実測の「**0.1483**」は **IT'IS LF 5.0 の格納値**。誤っていたのは値ではなく**ラベル**
  （"IT'IS LF の Skin は 0.0002" の "LF" の部分）。
- 真因は `LinkMaterialWithDatabase(ms, '材料名')` と**名前文字列**を渡すと既定の（非 LF）DB を
  引くこと。2026-07-29 に記録した罠が、8/3 のスクリプト化の過程で元に戻っていた。
  決め手は `DatabaseLink = 'Muscle'` ＝材料名の文字列しか保持していないこと。
- **判断: IT'IS LF 5.0 へ移行し、skin の 0.465 上書きは撤回した。**
  上書きの唯一の根拠が「DB 値 0.0002 が非物理的」であり、LF では 0.1483 で根拠が消える。
  加えて 0.465 は SimNIBS/ROAST の **scalp（皮膚＋脂肪＋筋の合成値）**で、Yoon-sun は
  `Skin` / `Fat` / `SAT` / `Muscle` を別エンティティで持つため**二重計上になる**。
- σ 一覧と LF/非 LF の差 → **`material-audit.md`**。

### ✅ #11 ViP 組織名 → DB 材料名の対応表 — **監査完了・誤対応なし**
- 全 59 組織の (ViP 名 → DB 材料名 → σ) を **`material-audit.md`** に保存した（レポートの材料表）。
- **誤対応は 1 件も見つからなかった**。多対1（7 材料）もすべて正当で、`Skin` に耳の皮膚が
  寄るのは **DB 側の公式な別名**（`Ear_skin_left` / `Ear_skin_right`）による。
- 頭蓋骨は `Bone (…)` ではなく **`Skull (…)`** を使っている（LF 5.0 は両方持ち、**海綿は 24% 違う**）。
- **σ の検算はハードコードした期待レンジをやめ、「リンク先 DB の格納値との直接照合」にした。**
  期待値をハードコードすると、別 DB を引く事故が「期待値を書き換えれば通る」形になり
  原理的に検出できない。監査側のレンジは重複なので撤去した（→ [#14](https://github.com/H4guk/insula-tTIS-TUS/issues/14)）。
- 場の側からの独立確認も取れている: `σ = 2·loss/|E|²` で逆算した値が既知値と一致
  （体積上位: Muscle 791 mL・灰白質 530 mL・Skin 397 mL・白質 393 mL・皮質骨 319 mL・CSF 80 mL）。

## レポートに明記する限界

- **電極モデルの簡略化**: 我々＝σ 1.6 の円板1層（直径 20mm・厚 3.5mm）/
  Inoue 2025 ＝導電ゴム（σ 0.1・厚 1mm）＋生理食塩水スポンジ（σ 1.6・厚 5mm）の 20mm 角。
- **粗 ROI**: Yoon-sun は島皮質を独立組織として持たないため球 ROI で切っている（先行研究は FreeSurfer 皮質表面頂点）。
  ROI はモデル上「白質」ラベルの領域に載る。**場の計算自体は正しく、限界は tTIS/TUS で共通なので比較の公平性は保たれる**。
- **個体差を扱えない**: Lite は Yoon-sun 1体固定。群レベルで安定な結果には島皮質で約20モデル必要（Inoue 2025）。
- **頭部モデル・ソルバー・電極モデルが先行研究と異なる**ため、選択性 ≈0.40 との**完全一致は求めず桁と傾向で照合**する。
- **`Commissura_anterior` がボクセル化されない**（頭部 1mm でも 0 voxel。2mm では前後とも空だったが
  1mm で `Commissura_posterior` は焼けるようになった）。極細の交連線維で、**ROI から遠く体積も
  無視できる**ため結果に影響しない。解像度をさらに上げてもセル数上限に近づくだけで得るものがない。
- **選択性の「脳」マスクは σ の帯（0.33–0.44）で切っており、脳以外が少量混ざる**
  （`Tendon\Ligament` 0.3676・`Eye (Lens)` 0.3453・`Trachea` 0.3420）。合計 **≲15 mL / 945 mL ≈ 1.5%**
  で、いずれも電場が弱い領域なので選択性の値は実質変わらない。また現在の「脳」は
  **大脳の GM+WM 中心**で、小脳（0.5766）・脳幹（Pons 0.5584）・視床（0.475）は帯の外。
  詳細 → `material-audit.md`。
- **絶対電流の独立検算が取れていない**（`J` の面積分が約25%過小・→ [#13](https://github.com/H4guk/insula-tTIS-TUS/issues/13)）。
  規約は σ 照合で確定しているが、二重確認ではない。
- **σ セットの選択が結果に効く**: 材料を IT'IS LF 5.0 にしたことで、非 LF の 2 kHz 評価値に対し
  **脳組織は 4〜5倍高く、頭蓋骨と Dura は逆に低い**。この選択と理由を明記する（→ `material-audit.md`）。

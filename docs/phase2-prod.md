# Phase 2 — prod 実装（計測）ノート

対応 Issue: [#7](https://github.com/H4guk/insula-tTIS-TUS/issues/7)
ブロッカー: Phase 1（#4）＝dev で電場が出ること

**dev（動かす）と prod（計測する）を分けた理由**: 動作確認の段で精度を気にすると手が止まる。
グリッド解像度・σ の厳密性・電流スケール・ROI 精度といった**値の正しさに関わる論点はすべてこちらに寄せる**。

---

## 目的
本番精度の設定で **TI 包絡線・ROI 内定量・選択性**を出し、先行研究と比較できる形にする。

---

## 指標の定義（ここが計測の芯）

| 指標 | 定義 | 備考 |
|---|---|---|
| TI 包絡線 | `2·min(|E1|, |E2|)`（Grossman の等方近似） | ペア1・ペア2 を**同一グリッド**で Run した E 場から作る |
| `TI_ROI` | ROI 内の**セル体積重み平均** | グリッドが非一様（graded）なので単純平均は歪む |
| **選択性** | **非標的領域の平均 EFE / 標的（ROI）の平均 EFE**（小さいほど良い） | Inoue 2025 の **Montage I ≈ 0.40** と照合する |
| 活性化閾値 | **0.3 V/m**（有効範囲 0.2–0.5 V/m の中点・Inoue 2025 採用値） | 「効いている」の判定に使う |

**選択性の定義を先行研究に合わせた理由**: 当初案は `ROI平均 / top1%平均` だったが、
先行研究と同じ定義にすれば **≈0.40 という外部の答え合わせが無料で手に入る**。独自定義に利点がない。

**電流**: Inoue 2025 の群レベル最適値 **I₁ = 0.891 mA / I₂ = 1.109 mA**（制約 I₁+I₂ = 2 mA）。
dev では 1V 駆動で計算し、**電場は線形なので後段でスケール**する。

## prod の設定

- **グリッド**: 頭部 **1mm** ＋ 体 **5mm**（Lite の上限 2000万セル以内。dev の実測で ≈1229万セル）
- **周波数**: ペア1 = 2000 Hz / ペア2 = 2010 Hz（差 10Hz ＝ 包絡線周波数）
- **★2シミュのグリッドを一致させる**（lec6 の教訓。Auto Grid は各シミュの自分の電極だけを囲むためズレる）
- **ROI**: 左島皮質・球 中心 (99.1, 295.0, 1562.2) mm / r = 10mm
  ※ 解析側のグリッド座標は **m** なので mm を 1000 で割る

## 解決すべき課題（Issue 化済み）

### #9 島皮質 ROI の頭皮からの深さが基準を下回る
- 実測 **25.0mm** に対し、ノートの基準は「頭皮から 3–4cm 深」。
- Yoon-sun は脳幅 127mm（MNI 標準 140mm の 0.91 倍）なので換算すると 27–36mm 相当＝**その下限をわずかに割る**。
- 選択肢: ①**基準を Yoon-sun スケールに再定義**する ②**ROI 中心を数 mm 内側へ寄せる**。
  どちらを採ったかと、粗 ROI であることをレポートの限界に明記する。

### #10 材料σの記録と実測が食い違う
- ノート記載「IT'IS LF の `Skin` は σ=0.0002（乾燥角質）」に対し、実測は **0.1483 S/m**。
- skin を 0.465（SimNIBS/ROAST の実効頭皮σ）に上書きしている**根拠がこの前提値に依存している**ので、
  評価周波数を明示して確認し、0.0002 の出所（IT'IS 5.0 側の値ではないか）を特定してから上書きの是非を判断する。

### #11 ViP 組織名 → DB 材料名の対応表を監査していない
- 対応づけは単語集合の一致（`[a-z0-9]+` 分割）＋手動辞書。**"もっともらしい別材料" に当たっても気づかない**。
- 59組織の **(ViP 名 → DB 材料名 → σ 値)** を出力して目視監査し、σ の期待レンジ自動チェックを常設する。
- 期待レンジ: 皮質骨 ~0.02 / 海綿骨 ~0.08 / CSF ~2 / 灰白質 0.1–0.3 / 白質 0.06–0.15。
- 監査した対応表は `docs/` に残す（レポートの材料表にそのまま使える）。

## レポートに明記する限界

- **電極モデルの簡略化**: 我々＝σ 1.6 の円板1層（直径 20mm・厚 3.5mm）/
  Inoue 2025 ＝導電ゴム（σ 0.1・厚 1mm）＋生理食塩水スポンジ（σ 1.6・厚 5mm）の 20mm 角。
- **粗 ROI**: Yoon-sun は島皮質を独立組織として持たないため球 ROI で切っている（先行研究は FreeSurfer 皮質表面頂点）。
  ROI はモデル上「白質」ラベルの領域に載る。**場の計算自体は正しく、限界は tTIS/TUS で共通なので比較の公平性は保たれる**。
- **個体差を扱えない**: Lite は Yoon-sun 1体固定。群レベルで安定な結果には島皮質で約20モデル必要（Inoue 2025）。
- **頭部モデル・ソルバー・電極モデルが先行研究と異なる**ため、選択性 ≈0.40 との**完全一致は求めず桁と傾向で照合**する。

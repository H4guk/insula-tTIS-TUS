## 優先度順の打ち手

### ★1. 感度解析を足す（基準④「信頼区間」への回答）— 最も効く

評価基準に **"verification, validation, and confidence intervals"** と明記されているのに、現状は CI が無い。
1体モデルでは統計的 CI は原理的に出せないが、**結論の頑健性は示せる**。しかも**追加計算がほぼ不要**。

| 振るもの | 手元にある値 | 何が言えるか |
|---|---|---|
| **脳マスクの定義** | tTIS 選択性 **0.3758**（WM+GM）/ **0.3132**（GM のみ）/ **1.3200**（材料全体）<br>TUS **0.1949**（脳broad）/ **0.2017**（GM+WM）/ **0.1527**（頭部非水） | **定義を変えても TUS < tTIS の順序は不変**＝結論①は定義に依存しない |
| **活性化閾値**（tTIS） | 0.3 V/m は有効範囲 **0.2–0.5** の中点（Inoue 2025）。ROI 平均 0.2265 に対し<br>閾値 0.2 → **113%** / 0.3 → **75.5%** / 0.5 → **45%** | **閾値 0.2 を採ると tTIS は「届く」に転じる**＝結論②は閾値の取り方に依存する。**正直に書けば誠実さの証拠になる** |
| **有効域の下端**（TUS） | Sharif 2025 の 3–30 W/cm²。ROI 平均 0.531 は下端の **17.7%** | 下端が多少動いても TUS は届かない＝**結論②の TUS 側は頑健** |
| **分離実装との再現性** | 体積平均 **1% 以内**・単一セル **6〜7%** | 数値の再現性の幅（測定済み） |

**やること**: 上の3つを表1つにまとめ、Discussion の限界の段に **「統計的 CI は1体モデルでは出せないので、
代わりに①定義依存性 ②閾値依存性 ③実装再現性の3つで頑健性を確かめた」** と書く。
**閾値 0.2 で tTIS が 113% に転じることを隠さない**——ここを書くかどうかで誠実さの印象が変わる。

> 追加で測るなら: **閾値を 0.2 / 0.3 / 0.5 と振ったときの「基準超えの ROI 体積割合」**（現在 0.3 で 1.5%）。
> 平均が 113% でも体積割合が小さければ「やはり領域としては届かない」と言えるので、**結論②を守れるか決まる**。
> `reach_volume.py` の閾値をパラメータ化すれば数分。

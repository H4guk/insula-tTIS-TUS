## 前提の修正（2026-08-28）

**独創性の評価を上方修正した。** 2026-08-28 に再調査した結果、**tTIS と TUS を同一頭部モデルで定量比較した研究は存在しない**
（[[ttis-tus-insula-novelty-survey]] の 2026-06-22 の結論が今も有効）。最も近いのは **TMS vs LIFU**（Brain Stimulation 2026）だが
**標的が DLPFC（浅部）で TMS は深部非対応**。tTIS と TUS の比較は**ナラティブレビューの定性表**（「TUS=mm級・TI=cm級」）のみ。

⇒ **本研究は空白を埋めただけでなく、既存の定性的理解を数値で覆している**（「絞れるが弱い TUS／絞れないが強い tTIS」）。
これは①科学的価値と②独創性の両方に効く**最大の武器**だが、**現在の仮版はそれを書いていない**。

## 優先度順の打ち手

### ★1. 感度解析を足す（基準④「信頼区間」への回答）— 最も効く

評価基準に **"verification, validation, and confidence intervals"** と明記されているのに、現状は CI が無い。
1体モデルでは統計的 CI は原理的に出せないが、**結論の頑健性は示せる**。しかも**追加計算がほぼ不要**。

| 振るもの | 手元にある値 | 何が言えるか |
|---|---|---|
| **脳マスクの定義** | tTIS 選択性 **0.3758**（WM+GM）/ **0.3132**（GM のみ）/ **1.3200**（材料全体）<br>TUS **0.1949**（脳broad）/ **0.2017**（GM+WM）/ **0.1527**（頭部非水） | **定義を変えても TUS < tTIS の順序は不変**＝結論①は定義に依存しない |
| **活性化閾値**（tTIS） | 0.3 V/m は有効範囲 **0.2–0.5** の中点（Inoue 2025）。ROI 平均 0.2265 に対し<br>閾値 0.2 → **113%** / 0.3 → **75.5%** / 0.5 → **45%** | **閾値 0.2 を採ると tTIS は「届く」に転じる**＝結論②は閾値の取り方に依存する。**正直に書けば誠実さの証拠になる** |
| **有効域の下端**（TUS） | Sharif 2025 の 3–30 W/cm²。ROI 平均 0.531 は下端の **17.7%** | 下端が多少動いても TUS は届かない＝**結論②の TUS 側は頑健** |
| **分離実装との再現性** | 体積平均 **1% 以内**・単一セル **6〜7%** | 数値の再現性の幅（測定済み） |

**やること**: 上の3つを表1つにまとめ、Discussion の限界の段に **「統計的 CI は1体モデルでは出せないので、
代わりに①定義依存性 ②閾値依存性 ③実装再現性の3つで頑健性を確かめた」** と書く。
**閾値 0.2 で tTIS が 113% に転じることを隠さない**——ここを書くかどうかで誠実さの印象が変わる。

> 追加で測るなら: **閾値を 0.2 / 0.3 / 0.5 と振ったときの「基準超えの ROI 体積割合」**（現在 0.3 で 1.5%）。
> 平均が 113% でも体積割合が小さければ「やはり領域としては届かない」と言えるので、**結論②を守れるか決まる**。
> `reach_volume.py` の閾値をパラメータ化すれば数分。

### ★3.5. 「届かせる道筋」を数字で書く（基準①②）— 追加計算ゼロ

**2026-08-28 の議論で浮上。結論が「どちらも届かない」で終わらず「何をすれば届くか」まで言える。**

手元の場から**すでに読める**数字:
- 参照駆動で **頭皮 6.098 MPa 対 脳内ピーク 2.048 MPa ＝ 約3倍**。MI を縛っているのは頭皮側
- 頭皮を焦点レベルまで下げられれば**音源を約3倍**、ISPPA は p² 比例なので **約9倍**
- **0.531 → 約 4.7 W/cm²**＝**有効域 3–30 に入る**（ROI 最大なら 27.9 で上端近く）
- 半分にできても4倍で 2.1（下端の 70%）
- 手段は**すべて非侵襲**: 大開口（F# を下げる）／複数素子の分散照射／結合水層を厚くして near-field を体外に出す
- tTIS 側は **1.32倍が必要**だが、壁が電流上限そのものなので逃げ道が少ない

⇒ Discussion の「改善方向」50 words を**この数字入りに書き換える**。語数は変わらない。
⇒ **含意**: TUS の弱さは**技術で埋められる**が、tTIS の絞れなさは**原理に近い**。結論③の一歩先。

### ★3.6. 「届かない」の意味を正確に書く（誤読防止）

**どちらの基準も「効果が報告されている強度の範囲」であって、神経の発火閾値ではない。**
- tTIS 0.3 V/m = 有効範囲 **0.2–0.5 の中点**（Inoue 2025）
- TUS 3 W/cm² = 神経調節の有効域 **3–30 の下端**（Sharif 2025）

⇒ 正確には **「先行研究が効果を報告している強度の下限に、標準実装・標準安全域では達しない」**。
**「効果がゼロ」と誤読されない書き方**にする。Conclusions の現行表現
（"neither method reaches the level at which it begins to work"）は正確だが、
**Abstract と Discussion でも限定を明示**する。

### ★3.7. 味覚再現の観点での結論を1文入れる（基準①）

**味覚再現を目的に固定すると優劣がつく＝TUS。** Discussion の Level 2 段に1文。

| 味覚再現が要求するもの | tTIS | TUS |
|---|---|---|
| 限局領域を狙う空間精度（Mazzola の誘発ゾーンは小さい） | **焦点を結ばない**（50.5 mL に散る・過半が飛び地） | 焦点を結ぶ（2.58 mL） |
| 多点を独立に制御（Level 2 の必須条件） | 多対にしても干渉パターンが変わるだけで**独立した点を作れない** | **フェーズドアレイで複数焦点**（既存技術） |
| 時間制御 | ビート周波数 | パルス列 |
| 強度 | 75.5%（**壁は電流上限＝埋めにくい**） | 17.7%（**壁は頭皮＝埋められる**） |

⇒ **「埋められる弱点を持つ TUS と、埋められない弱点を持つ tTIS」**。味覚再現を目指すなら TUS。
⚠️ ただし多点制御と時間制御は**今回測っていない**（tier-1 の外）。**焦点の有無からの外挿**であることを明示する。

## 見立て

賞は **1〜3位の3枠のみ**（佳作・特別賞は無い。2024年の受賞は EPFL / UPenn / 嘉泉大の3名）。
学部生で3枠に入るのは容易ではないが、**③④の厚さは相当強い**。
**①②を Abstract で立て、④に感度解析を足し、★3.5 で「届かせる道筋」を数字にする**のが最も費用対効果が高い。
**決め手は Abstract の 100 words** ——「未踏の比較である」「結果が反直感的である」「届かせる道筋がある」を
そこで言えるかどうか。材料は 2026-08-28 の議論で全て揃った。

## 今回やらないこと（来年に回す）

**味覚ゾーンを標的にした大開口 TUS の実証**は今回の提出に含めない。理由:
1. **味覚ゾーンの ROI 定義が難物** — Mazzola 2017 は臨床の電気刺激研究で「中背部島皮質・後部短回」という記述。
   MNI と個体モデルの対応づけが要り、**ここが弱いと主張全体が崩れる**
2. **時間** — 締切まで2ヶ月だが #22（9/30）があるので実質1ヶ月。ROI 定義 → 大開口設計 → 複数条件 Run → 再計算 → 執筆は間に合わない
3. **tier-1 が崩れる** — TUS だけ改良すると「標準 vs 標準」でなくなり、**この研究の一番の売りを自分で壊す**

⇒ **2027年のコンテストに「解決編」として出す**（毎年開催）。今年出しておけば来年
「前年に示した限界を本研究で解決した」と書けて、**継続性が評価される**。

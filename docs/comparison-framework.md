## 1. 研究の問いと「味覚再現の要件」（なぜこの比較か）

**問い**: 依存症治療に向け**島皮質**へ非侵襲で刺激を送るのに、**tTIS と TUS のどちらが適するか**を同一シミュ環境で定量比較する。

必要な性能は「味覚を再現する」という最終目標が決める。脳側の2本がそれを規定する:

- **存在証明・標的（Mazzola 2017, Ann Neurol）**: ヒト島皮質への**局所電気刺激で味覚が誘発**（651刺激中15回=2.7%）、誘発ゾーンは**中背部島皮質（後部短回）の限局領域**（味覚・嗅覚・口腔体性感覚の統合野）。⇒「島皮質を局所刺激すれば味覚は作れる」直接証拠＋標的（ただし侵襲的）。
- **符号化＝必要精度（Avery 2020, J Neurosci・7T fMRI）**: 味質に一貫した優位領域なし＝**地図説を否定・分布的な集団符号（population code）**。⇒ 単一焦点では generic な味覚は起こせても、**特定の味"質"は撃ち分けられない**。（マッピング説 vs 集団符号の判別自体は #15 [[insula-taste-mapping]]）

### 要件の2階層
- **Level 1 — 味覚を"起こす"**: 中背部島皮質を**安全・十分な強度・選択的**に活性化できるか ＝ 深部到達・安全・焦点性・選択性。**tTIS vs TUS の比較はこの Level 1 を答える**。
- **Level 2 — 味"質"を"再現"する**: 集団符号ゆえ**分布パターン＋時間制御**が要る ＝ 多点/アレイ（tier-1 外）。単一焦点では原理的に不足。

> **この研究の主張＝「味覚に"届く"手法の比較（Level 1）＋味"質""再現"の限界の明示（Level 2）」**。

## 2. 比較の条件（tier-1・動かさない）

- **同一 Yoon-sun**・**同一 ROI**（左島皮質 球 中心 (99.1,295.0,1562.2)mm・半径10mm）・**同一指標形式**（選択性＝非標的/標的）。
- **標準実装 vs 標準実装**: tTIS＝2対 Montage I（T7–P7 / Fp1–Fp2）/ TUS＝単一素子 集束お椀。最適化・アレイは非対象。
- **同一安全水準＝各手法を自らの臨床標準の安全上限で評価**: tTIS＝合計 2mA（Inoue の 0.891/1.109mA）/ TUS＝全体 MI<1.9（FDA/ITRUSST）。
- **通約**（V/m ≠ Pa）: **無次元の比（選択性）**と**閾値正規化**（各手法の活性化閾値に対する割合）で同じ土俵に乗せる。

## 4. 足りない軸 → **2026-08-27 決定: 抽出する**（工程 5-1〜5-3）

いずれも**保存済み Run 結果の後処理のみ・再 Run 不要**:
- ✅ **5-1 TUS 焦点サイズ**（A）: `tus_focus_size.py` で実測（2026-08-27）。**2.58mL / 側方 16.6・11.2mm / 軸 49.7mm / 等価球径 17.0mm**。設計値 7.3/61.7mm に対し**側方は 2.3倍太く、軸はやや短い**（脳マスクで切れている分を含む）。
  - 副産物1: **脳内ピークは ROI 中心から 10.3mm 手前**（s=38.6mm・設計焦点 48.5mm より 9.9mm 浅い）＝**5-3 の TUS 側も同時に確定**。ROI 中心の \|p\| はピークの 69%。
  - 副産物2: **-6dB 領域の 41.9% しか ROI 内に入らない**（残りは経路上の側頭葉ほか。`phase4-tus.md` の「s=21–33 に 1.5–2.7MPa」と整合）。
  - 副産物3: **頭皮から脳内焦点まで -6dB を下回る谷が無い**（頭部全域版 19.5mL・軸 88.2mm が頭皮の山と連結）。頭皮の山 6.404MPa は脳内ピーク 2.048MPa の**3.1倍**で、脳内ピーク基準の -6dB は頭皮にとって -16dB＝緩い線なので連結自体は当然だが、**F#=1.21 の強集束にもかかわらず脳内で集束の利得が立っていない**ことを領域の形から示す＝「頭皮 near-field 律速」の別表現。
- ◐ **5-2 tTIS 焦点サイズ**: `ti_focus_size.py` を 2026-08-27 に実行。**場は正しく再現できた**（s1/s2=0.6198≒Phase2 0.6200・ROI 中心 TI 0.2229 V/m≒Phase2 平均 0.2265・σ=0.3480(WM)・脳マスク 945.1mL）が、**測り方（グローバルピーク基準の -6dB）が tTIS には成立しないと判明**。数値は未確定。
  - **判明した事実**: **脳内 TI 最大は 2.4122 V/m @ (48.5,274.5,1482.5)＝ROI 中心から 96.6mm**（ほぼ頭の反対側）。tTIS は**電極近傍が最大**で「グローバル最大＝標的」という構造が無い（Phase2 既記の「材料全体 TI max 8.4V/m は電極縁」が脳内でも同型）。ピーク基準の -6dB 閾値 1.2089 V/m は**標的 TI 0.2229 の 5.4倍**なので ROI 周辺は 1 セルも入らず、脳内 -6dB=1セルは領域でなく孤立スパイク。⇒ **出力の「TUS より 2576倍小さい」「①は書き換え」は無効**。
  - **含意（失敗以上の中身）**: tTIS は島皮質に**「焦点」と呼べる極大を作れていない**。選択性 0.3758 は「緩やかな裾の中で標的がやや高い」意味であって集束スポットではない。Phase2 の「2mA で閾値の75%・閾値超えは ROI の1.5%」と一貫する。
  - **測り直しの方針**: 基準をグローバルピークから**標的（ROI 内の値）**に移し、「**標的レベルの刺激が及ぶ範囲**」を両手法共通の問いとして測る。**TUS 側も同じ基準で測り直して揃える**。先に確認するのは**島皮質近傍に局所極大があるか（＝小さくとも焦点があるか）／単調な裾か**。
- ◐ **5-3 焦点位置ズレ**: TUS 側は 5-1 で確定（10.3mm）。**tTIS 側は「ズレ」という概念自体が成立しない可能性**（グローバル最大が電極側 96.6mm 先＝標的からの距離を報告しても意味が薄い）。5-2 の測り直しと同時に定義し直す。
- 決定理由: ①#21 締切 2026-10-31 まで2ヶ月 ②再 Run 不要で低コスト ③**A は tTIS/TUS で差が出る discriminator**＝Mazzola 2017 の「中背部島皮質の限局した味覚誘発ゾーンに収まるか」を言える唯一の軸。
- （無くても §6 の芯は成立するが、設計値のままでは「設計上こうなる」しか言えない。）

**コレクションの穴**: 脳側は Mazzola/Avery の2本が事実上すべて。**デバイス側（電気味覚・デジタル味覚＝Ranasinghe/Nakamura 等）は未収集**。Level 2 を厚くするなら手動投入（add-paper）で追加。

## 6. 結論の芯（暫定・実測で確定済み）

> **①焦点性は TUS が優位** ——**⚠️ 2026-08-27 に保留（5-1）→ 論点が変わった（5-2）**。
> 5-1: 比の量（脳内選択性 0.20 < tTIS 0.38）では TUS だが、**絶対サイズは 2.58mL・等価球径 17mm・側方 16.6mm＝設計値の2.3倍**で、Mazzola の味覚誘発ゾーン（限局領域）には粗い。
> 5-2: **tTIS は島皮質に「焦点」と呼べる極大を作れていない**（脳内 TI 最大は標的から 96.6mm の電極側）。⇒ 論点は「どちらの焦点が小さいか」ではなく、**「TUS は粗くとも標的に焦点を結ぶ／tTIS はそもそも焦点を結ばず裾の中で標的がやや高いだけ」という質の違い**になる可能性が高い。**5-2 の測り直し（標的基準）が確定するまで①の文言は書かない**。
> **②どちらも標準安全域では焦点線量が活性化閾値ぎりぎり**（tTIS 閾値の75%・TUS 有効域下端）。
> **③苦しさの質が違う**——tTIS は**絶対強度**（2mA では届かない）、TUS は**頭皮 near-field**が駆動上限を縛る。
> **④味"質"の再現（Level 2）はどちらも単一焦点では原理的に届かない**（Avery の集団符号）＝共通の天井・今後はアレイ/多点へ。

＝ 島皮質ターゲットでは「**選択性なら TUS・簡便さ/頭皮負荷の無さなら tTIS**」の条件付き結論。最終判断は味覚サブ領域の撃ち分け要件（焦点サイズ A）次第。

# 手法・評価枠組み

## 研究の問い
島皮質に非侵襲で刺激を届けるのに **tTIS** と **TUS** のどちらが適するかを、同一頭部モデル・同一 ROI で比較する。

## 共通の土台
- **頭部モデル**: Yoon-sun v3.1（IT'IS ViP・Sim4Life.lite 同梱の 1 体固定）。全身モデルだがグリッドで頭部だけ精細化。
- **島皮質 ROI**: 粗 ROI（球）。中心 (99.1, 295.0, 1562.2) mm・半径 10mm（左島皮質）。
  - MNI ±38mm を Yoon-sun 脳幅で補正（127/140=0.91 → ±34.5mm）。AC と同じ前後・高さ。
  - Yoon-sun は島皮質を独立組織として持たない（白質に吸収）ため、解剖学的座標に基づく球で定義。
  - 限界: ROI はモデル上「白質」ラベル領域に置かれるが、場の計算は体積導体全体で解くため電場値は正しい。
    この限界は tTIS/TUS で共通なので比較の公平性は保たれる（「ROI は絶対精度より両手法で同一が本質」）。

## tTIS 側（フェーズ1）
- **モンタージュ**: Montage I（Inoue 2025・島皮質狙い最頻・focality 最良）。
  - ペア1 = T7–P7（左側頭を縦・2000 Hz 相当）/ ペア2 = Fp1–Fp2（前頭を横・2010 Hz 相当）。
  - 群レベル最適電流 I1=0.891 / I2=1.109 mA（I1+I2=2mA）。
- **物理**: Electro Quasi-Static（EQS・準静的）。σ は IT'IS LF DB にリンク（頭部 59 組織）。
  - **skin 系は実効頭皮 σ 0.465 S/m に上書き**（IT'IS の乾燥皮膚値 0.0002 は tES で非物理的・SimNIBS/ROAST 標準へ）。適用済み。
  - **★駆動電極(Elec_*)にも材料σを付与する**（σ=1.6 S/m・食塩水スポンジ相当の簡略化）。これが無いと Voxeler が電極を
    ボクセル化せず Dirichlet が実体を持たず全点 NaN になる（2026-07-30 に真因確定。詳細は progress-log.md）。
- **TI 定量**: 2 場の各点振幅から `TI = 2·min(|E1|,|E2|)`（Grossman 等方近似）。ROI 内は体積重み平均。
- **1V 駆動 → 後段でスケール**（EQS は線形）。Inoue の電流比再現は計算後に。

## 評価軸
- **選択性** = 非標的領域の平均 EFE / 標的(ROI)の平均 EFE（小さいほど良い）。
  - 先行研究 Inoue 2025 の Montage I ≈ 0.40 と桁・傾向で照合（頭部モデル・ソルバー・電極モデルが違うので完全一致は求めない）。
- **活性化閾値** 0.3 V/m（0.2–0.5 の中点・Inoue 2025 採用値）を「効いている」の判定に使う。

## TUS 側（フェーズ2・未着手）
同一 Yoon-sun・同一 ROI で音場を組み、同一指標で比較 → フェーズ3（比較・最適手法判定）へ。

## 主要な限界（レポート・論文用）
- Yoon-sun 1 体固定＝個体差・群レベルの一般化は扱えない（Lite の制約）。
- 電極は円板ソリッド（Inoue はスポンジ+ゴム）＝簡略化。
- TUS は頭蓋の音響収差モデル化が難しく結果が仮定依存。

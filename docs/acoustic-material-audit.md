## 採用 DB と property 名

- **採用 DB = `IT'IS 5.0`**。音響値は IT'IS 3.0〜5.0 でほぼ同一（Bone(Cortical) は全 DB で ρ=1908 / c=3514.86 / α0=54.553 が一致）。最新かつ非線形 B/A を持つ 5.0 を採用（tTIS が LF 5.0 系だったのとも整合）。
- 音響 property の正式 VariableName（`AllProperties` から名前で直接読む）:

  | VariableName | 記号 | 意味 | 単位 |
  |---|---|---|---|
  | `mass_density` | ρ | 密度 | kg/m³ |
  | `sound_speed` | c | 音速 | m/s |
  | `attenuation_alpha` | α₀ | 減衰係数 | Np/m/MHz |
  | `attenuation_b` | b | べき乗則の指数 | – |
  | `nonlinearity_ba` | B/A | 非線形パラメータ | – |

- **減衰モデル**: `α(f) = α₀ · f^b`（α₀ は Np/m/MHz、f は MHz）。減衰は α₀ と指数 b の**2値**で表される。⚠️ probe 初版は set の順不同なめで `attenuation_b`（指数）を「減衰」に誤採用していた（2026-08-20 補正・[[2026-08-20]]）。
- **B/A**: 線形 Pressure Acoustics で解くなら不要。多くの組織で 0（未収載）、Blood/Fat/Lymphnode/Muscle/Tongue 等の一部だけ実測値を持つ。

## 検証と限界

- **検証**: 全材料を DB 側と exact 名一致で解決（表記ゆれ吸収の normalized/alias に頼らず一致）。property は名前で直接読む（推測 pick を廃止＝tTIS #14「期待値ハードコードは事故を隠す」の音響版）。
- **★頭蓋の限界（CT 無し一様骨近似）**: 本モデルには CT が無く、頭蓋は Yoon-sun のセグメントに従い **Skull (Cortical) / Skull (Cancellous) の DB 一様値**で近似する。実頭蓋は多孔質で個人差が大きく、TUS では音速・減衰・位相収差の最大の不確かさ源。Skull(Cortical) の c=2813.69 と Bone(Cortical) の c=3514.86 が別値である点も DB の作りに依存。→ #36 比較の「限界」節（4-8）に明記する。
- **周波数依存**: DB 値は α₀·f^b の係数なので、実効減衰は 4-2 で決める駆動周波数 f に依存する。f を決めた時点で各材料の実効 α [Np/m] が確定する。
- **非線形**: 線形音響（Pressure Acoustics）で解く前提なら B/A は使わない。高強度で非線形を入れる場合のみ B/A 列を使用。
